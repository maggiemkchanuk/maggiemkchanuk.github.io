## Picturebook catalogue updates

When adding a picturebook to Authors or Illustrators, check the Picturebook Reading List in the same update. Add any missing title to its best-fitting existing theme and keep one entry per work. Record translations and editions with the original entry where applicable. When adding to the thematic list, also check the bibliographies of any featured authors or illustrators credited on the book. Keep creator credits and publication details consistent across pages.
